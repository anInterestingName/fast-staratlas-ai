## 6. SQL 与迁移

### 6.1 脚本影响

| 脚本 | 是否修改 | 内容 |
| --- | :---: | --- |
| `doc/sql` 全量脚本 | 否 | 无业务对象，不写空 DDL |
| `doc/sql` 升级脚本 | 否 | 无存量结构可升级 |

### 6.2 迁移流程

```mermaid
flowchart LR
    A[准备 PostgreSQL 实例] --> B[配置 DATABASE_URL]
    B --> C[发布应用]
    C --> D[GET /ready 执行 SELECT 1]
    D -- 失败 --> E[检查实例与配置，不回滚结构]
```

### 6.3 DDL/数据处理

无 DDL。无历史数据回填。应用启动不执行 `create_all` 或迁移。

重复执行策略：`/ready` 的 `SELECT 1` 可重复，无结构副作用。

锁表与耗时风险：不涉及。

### 6.4 回滚

- 代码回滚前提：旧代码不依赖任何新库对象。
- 数据库回滚步骤：无对象可删；无需执行 DROP。
- 不可逆数据：无。

## 7. 隔离、一致性与安全

- 归属隔离：不涉及。
- 逻辑删除：不涉及。
- 并发一致性：无业务写入。
- 敏感数据：连接串只存在于环境变量/本地示例配置；SQL、响应和常规日志不得包含真实凭据。未要求脱敏，不设计脱敏流程。
